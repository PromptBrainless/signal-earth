# SIGNAL EARTH

SIGNAL EARTH – Brand- und Projekt-Repository.

## Inhalt
- Frontend (Vite + TypeScript)
- Server / Backend-Komponenten
- Dokumentation unter `docs/`
- Agent-Anweisungen: `AGENTS.md` und `AGENTS.project.md`

## Start
```bash
npm install
npm run dev
```

- `src/` – Quellcode
- `server/` – Server-Logik
- `docs/` – Dokumentation
- `public/` – statische Assets
